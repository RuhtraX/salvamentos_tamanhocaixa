> **Sizebox** - *"The free sandbox game & creative tool for size enthusiasts, originally created by Aiiko"*

Este repositório contém minha coleção pessoal de saves (arquivos `.json`) do jogo/ferramenta **Sizebox**. Aqui você encontrará cenários e configurações que criei ou modifiquei para explorar ao máximo as possibilidades criativas do Sizebox.

---

## ⚠️ ATENÇÃO: Dependência de Modelos Personalizados

**Os saves deste repositório NÃO funcionarão com a instalação padrão do Sizebox.**

Eles dependem de **modelos de personagens e cenários** que **não vêm incluídos** na instalação original do jogo. Estes modelos precisam ser adquiridos e instalados separadamente.

### O que você precisa fazer:

1. **Adquirir os modelos externos** (personagens, cenários, objetos) se possível

2. **Instalar os modelos** na pasta correta do Sizebox:
   - `Sizebox/Models/[FemaleNPC,Giantess,Objects,Scenes]`

### 🚫 Este repositório NÃO contém:
- Arquivos de modelos (`.macro`, `.object`, etc.)
- Texturas, sons ou qualquer asset proprietário

### ✅ Este repositório contém APENAS:
- Arquivos de save (`.json`) que referenciam modelos já instalados no seu sistema

> **Nota:** Se você carregar um save sem ter os modelos necessários, o Sizebox provavelmente exibirá erros ou personagens/cenários ausentes (substituídos por placeholders ou nada).

## 🚀 Como Usar (com os modelos instalados)

1. **Clone o repositório**:
   ```bash
   git clone https://github.com/RuhtraX/salvamentos_tamanhocaixa.git
   ```

2. Localize a pasta de saves do Sizebox:

    `Sizebox/Saves/`

3. Copie os arquivos .json desejados para a pasta de saves.

4. Abra o Sizebox e carregue o save normalmente.
